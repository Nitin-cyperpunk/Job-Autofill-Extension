JobFill detection test pages

Load a debug build (npm run build:debug or npm run dev), open a page, then use the popup's debug panel or jobfill.overlay() in the JobFill console context.

  • Simple HTML form — labels, fieldsets, file, contenteditable, honeypot
  • Google Forms–style — ARIA radios/checkboxes/listbox, aria-labelledby
  • React form — controlled inputs, useId, conditional field
  • Dynamic form — late fields, "add another", hidden steps, DOM noise
  • Visually separated labels — grids, tables, loose text
